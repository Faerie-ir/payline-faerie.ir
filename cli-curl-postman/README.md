# Faerie Payline — OpenAPI 3.1, Postman Collection & Bash CLI

مجموعهٔ ابزارهای استاندارد آزمایش و تولید خودکار کد کلاینت برای **Faerie Payline**:
- **`openapi.yaml`**: مشخصات کامل **OpenAPI 3.1** (قابل ورود به Swagger UI، Scalar و ابزارهای `openapi-generator` برای تولید کلاینت در هر زبان دیگر).
- **`faerie-payline.postman_collection.json`**: کالکشن آماده برای **Postman** و **Insomnia**.
- **`faerie-payline-cli.sh`**: ابزار خط فرمان Bash/cURL برای تست آنی در ترمینال.
