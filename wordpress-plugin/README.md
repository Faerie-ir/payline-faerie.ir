# Faerie Payline SDK — افزونهٔ رسمی وردپرس و ووکامرس (`WordPress + WooCommerce`)

افزونهٔ آمادهٔ نصب برای اتصال وب‌سایت‌های **وردپرسی** و فروشگاه‌های **ووکامرس (`WooCommerce`)** به درگاه **Faerie Payline**.

## قابلیت‌ها
1. **درگاه کامل تسویه‌حساب ووکامرس (`WC_Gateway_Faerie_Payline`):**
   - تبدیل خودکار واحد پول سفارش (`IRR` ریال، `IRT` تومان، `IRHT` هزار تومان) به تومان.
   - بازگشت خودکار ۲ ثانیه‌ای خریدار از درگاه فائری به سایت شما و **استعلام قطعی سمت سرور** (`GET /api/v1/iap/status/{id}`).
   - ثبت کد رهگیری شاپرک و شمارهٔ فاکتور رسمی فائری در یادداشت سفارش و متادیتا.
2. **شورت‌کد مستقل `[faerie_pay]` (حتی بدون نصب ووکامرس!):**
   - برای وبلاگ‌ها، سایت‌های آموزشی یا لندینگ‌پیج‌ها کافی است شورت‌کد زیر را در هر برگه بگذارید:
   ```text
   [faerie_pay sku="vip_monthly" label="خرید اشتراک ویژه با فائری"]
   ```

## آموزش نصب گام‌به‌گام در وردپرس
1. فایل آمادهٔ نصب را از مسیر `/developers/docs/sdk/wordpress-plugin-installable` روی سایت دانلود کنید. بستهٔ اصلی ZIP تو در تو ندارد؛ سرور ZIP افزونه را هنگام دانلود از سورس همین پوشه می‌سازد.
2. در پیشخوان وردپرس به **افزونه‌ها ← افزودن تازه ← بارگذاری افزونه** بروید، فایل ZIP را انتخاب و فعال کنید.
3. برای ووکامرس: در پنل توسعه‌دهندگان فائری یک آیتم با تیک **«مبلغ دلخواه (Custom Amount)»** و شناسهٔ مثلاً `wc_order` بسازید، سپس در **ووکامرس ← پیکربندی ← پرداخت‌ها ← درگاه پرداخت فائری** کد `pl_...` و شناسهٔ `wc_order` را ذخیره نمایید.
